Memahami Persebaran
Fasilitas Perbankan

Website ini merupakan tugas besar Mata Kuliah Internet of Things (IoT) Program Studi Perencanaan Wilayah dan Kota, Universitas Diponegoro.

Peta WebGIS ini menampilkan informasi spasial mengenai persebaran fasilitas bank—termasuk kantor cabang, ATM, dan mesin EDC—yang dapat diakses masyarakat di kawasan bersejarah Kota Lama Kota Semarang.

Dosen Pengampu:
Assoc. Prof. Dr. Anang Wahyu Sejati, S.T., M.T.

Program Studi: Perencanaan Wilayah dan Kota
Fakultas: Teknik, Universitas Diponegoro
🏛️
Kawasan Kota Lama
Kawasan bersejarah di jantung Kota Semarang dengan identitas kolonial yang kuat dan aktivitas ekonomi yang padat.
📊
Data Spasial QGIS
Peta dikembangkan menggunakan QGIS dan diekspor ke format web melalui plugin qgis2web berbasis OpenLayers.
🔍
Analisis Persebaran
Visualisasi persebaran fasilitas bank untuk mendukung kajian aksesibilitas dan perencanaan wilayah berbasis data.
🌐
WebGIS Interaktif
Antarmuka berbasis web yang responsif memungkinkan pengguna menjelajahi data secara langsung di browser.
